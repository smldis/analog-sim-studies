# ASS Flow planning prototype

This directory contains a bounded, non-production prototype of the
Python-native static planning contract described in [`PLANNING.md`](PLANNING.md).
It is not yet a declared Analog Sim Studies unit or an installable compatibility
contract.

Run its focused tests from this directory with:

```bash
python -m pytest -q
```

See [`IMPLEMENTATION.md`](IMPLEMENTATION.md) for current progress and known
stubs.
